# 🎉 Virtual Raksha Bandhan Ceremony 💖

A deeply emotional and cinematic web experience celebrating the sacred bond between siblings, designed for long-distance Raksha Bandhan celebrations.

## ✨ Features

### 🌟 Interactive Ceremony Steps

1. **Welcome Screen with Personalization**
   - URL-based personalization: Add `?name=BrotherName` to the URL
   - Or enter brother's name through an input box
   - Animated sister avatar with welcoming message
   - Playful "No isn't an option" interaction

2. **Tilak/Bottu Ceremony**
   - Choose from 3 authentic tilak styles:
     - Traditional Round Red Kumkum with Akshat (Rice grains)
     - Elegant Chandan (Sandalwood) & Red Tilak
     - Royal Trishul / Festive Tilak
   - Animated hand applies the chosen tilak with sparkle effects
   - Heartfelt caption about blessings

3. **Aarti/Harathi Blessing**
   - Beautiful ornate golden Aarti Thali with glowing diya
   - Animated incense smoke particles
   - Click to perform 360-degree circular Aarti animation
   - Glowing light effects around brother's photo

4. **Rakhi Selection & Tying**
   - Choose from 4 beautiful Rakhi designs:
     - Traditional Zari
     - Sacred Rudraksha
     - Modern Minimalist Gold
     - Colorful Floral
   - Animated Rakhi tying on wrist with pulse effects
   - Sparkle and glow animations

5. **Sweet Feeding**
   - Select from 4 traditional sweets:
     - Kaju Katli
     - Gulab Jamun
     - Motichoor Laddu
     - Rasgulla
   - Animated sweet feeding with confetti effect
   - Delightful message about sweet memories

6. **Virtual Warm Hug & Blessings**
   - Heartwarming animated sister figure
   - Screen-filling hug animation with pulsing hearts
   - Floating festive particles
   - Interactive blessing button reveals heartfelt message

7. **Grand Finale**
   - Spectacular fireworks and confetti burst
   - Personalized parchment letter with loving message
   - Download memory card as PNG
   - Share on WhatsApp functionality
   - Replay entire ceremony

**Method 1: URL Parameter**

**Method 2: Input Field**
- Enter brother's name when prompted on the welcome screen

1. **Click the audio button** (🔊) in the top-right to enable background music

4. **Download the memory card** at the end to keep as a memento

## 🎁 Customization Tips

### Change Brother's Photo
Replace the placeholder with actual photo by modifying `.photo-placeholder` in CSS and adding an image element.

### Adjust Colors
Edit CSS variables in `:root` section of `styles.css`:
```css
--primary-maroon: #8B1538;
--warm-gold: #D4AF37;
--bright-gold: #FFD700;
--ivory: #FFFFF0;
```

### Add Your Own Messages
Edit the caption text in `script.js` within each ceremony section.

### Change Animation Timing
Adjust `setTimeout` delays in `script.js` to make transitions faster or slower.
