# 🚀 Quick Start Guide - Virtual Raksha Bandhan Ceremony

## ⚡ Get Started in 30 Seconds

### Step 1: Open the Website
Simply double-click on `index.html` or open it in your web browser.

### Step 2: Enter Your Brother's Name
- You'll see a beautiful welcome screen with an animated sister avatar
- Enter your brother's name in the input field
- Click "Continue 💖"

### Step 3: Enjoy the Journey!
Follow the interactive ceremony steps - each one is magical! ✨

---

## 🎯 Quick Navigation

### Using URL Parameters (Advanced)
Skip the name input by adding it to the URL:
```

```

### Audio Control
- Click the 🔊 button in the top-right corner to toggle background music

## 🎨 Customization Ideas

Want to personalize it more? Here are some quick edits:

### Change the Sister's Message (Easy)
1. Open `script.js` in a text editor
2. Find the line with "Hello my dearest"
3. Edit the text to your liking
4. Save and refresh the page

### Add Your Brother's Photo (Medium)
1. Place a photo named `brother.jpg` in the same folder
2. Open `styles.css`
3. Find `.photo-placeholder`
4. Add: `background-image: url('brother.jpg');`
5. Add: `background-size: cover;`

### Change Colors (Easy)
1. Open `styles.css`
2. Find the `:root` section at the top
3. Change the color values
4. Save and refresh

## ❓ FAQ

**Q: Do I need internet to use this?**
A: Only for the first load to get the Google Fonts. After that, it works offline!

**Q: Can I use my own photos?**
A: Yes! Check the "Customization Ideas" section above.

**Q: The ceremony is too fast/slow. Can I change it?**
A: Yes! Edit the `setTimeout` delays in `script.js`.

**Q: Can I translate it to my language?**
A: Absolutely! Edit the text in both `index.html` and `script.js`.

**Q: Is this free to use?**
A: Yes! Use it for personal, non-commercial purposes.

**Q: Can I modify it?**
A: Yes! All code is open and editable. Make it your own!

**Q: Does it save my progress?**
A: Currently no, but you can complete the ceremony in one sitting (5-7 minutes).

**Q: Can I add more steps?**
A: Yes! Duplicate a screen section and add your custom step.
